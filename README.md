# 🐱 Рыжик и Старый Загородный Дом

**Атмосферная narrative cozy life-sim игра**

Играй за рыжего кота по имени Рыжик в старом загородном доме. Подружись с 10 персонажами, выполни их квесты, оживи двор и раскрой тайны прошлого.

---

## 🎮 Как играть

| Клавиша | Действие |
|---------|----------|
| WASD / Стрелки | Движение |
| Shift | Бег |
| E | Говорить с NPC |
| Q | Журнал квестов |
| I | Инвентарь |
| M | Включить музыку |
| ESC | Закрыть панели |

---

## 🌟 Персонажи

| Имя | Квест | Особенность |
|-----|-------|-------------|
| **Лёха** | Старая кассета | Гитарист, знает тайны дома |
| **Игорь** | Пропавший медиатор | Рокер, мини-концерты |
| **Настя** | Фото со светлячками | Фотограф, альбом воспоминаний |
| **Лиза** | Потерянные наклейки | Украшает двор, хаотичная энергия |
| **Маг** | Колокольчик луны | Появляется только ночью |
| **Соня** | Лесная тропа | Путешественница, знает лес |
| **Нэна** | Странные записи | Раскрывает историю дома |
| **Кристина** | Сломанный фонарик | Чинит и улучшает двор |
| **Даня** | Коробка сокровищ | Изобретатель, крафтер |
| **Прохор** | Ремонт забора | Строитель, сильный молчун |

---

## 🌍 Локации

- **Старый дом** — с кухней, гостиной, верандой, чердаком
- **Двор** — костёр, качели, гамак, гирлянды
- **Лес** — тропинки, туман, заброшенный колодец, домик на дереве
- **Пруд** — мостик, лодка, лягушки, кувшинки
- **Теплица** — открывается после квеста «Колокольчик луны»

---

## ⚙️ Технологии

- **React** + **TypeScript** + **Vite**
- **Phaser.js 3** — игровой движок
- **Zustand** — state management
- **Web Audio API** — процедурный звук

---

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Локальный запуск
npm run dev

# Сборка для GitHub Pages
npm run build
```

Открой `http://localhost:3000` в браузере.
